# py_aggregation_cat
python code - Python translation of the R aggregation script for Man-Made catfiles: aggregates the catfiles of each entity / risk / segment / run (and pool_property files) and computes mean / AEP200 / STEC / OEP200
Optional group view (group=True in main.py): sums the strips of all entities converted to euros (fx_rates) per risk and in total, and writes Gross_MM_reconciliation_Group.xlsx.
